# Stochastic Lightcuts Image Synthesis

A WebGPU-based renderer implementing Ray Tracing, Lightcuts, and Stochastic Lightcuts.
 
Interface self explanatory.

## How to Run

0. **IF ALREADY BUILT:**
    - Open `dist/index.html` in a WebGPU-compatible browser (e.g., Chrome, Edge)

1. **IF NOT ALREADY BUILT:**
    ```bash
    npm install
    ```

2.  **Start Development Server:**
    ```bash
    npm run dev
    ```
    Open the provided local URL in a WebGPU-compatible browser (e.g., Chrome, Edge).

3.  **Build for Production:**
    ```bash
    npm run build
    ```
    This generates a single `dist/index.html` file containing all code and assets, ready to be opened directly in a browser.
